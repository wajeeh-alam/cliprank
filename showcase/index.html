04 Availability

The costly part is intentionally off.

This public site is a static product walkthrough, so it needs no API keys and creates no surprise compute bill. The full Rails + ML deployment supports real uploads, transcription, background processing, private media, and authenticated playback. Service and storage credentials are configured by the operator—never supplied by visitors.
